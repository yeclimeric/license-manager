# 雪松软件授权系统社区版项目全局信息

## 项目简介

雪松软件授权系统社区版是一套面向软件授权商业化场景的开源系统，提供管理端 Web UI、授权管理后端、客户端激活与心跳接口，以及用户自助服务相关后端能力。本仓库当前升级原则是保持社区版产品边界，不因参考企业版而引入企业版专属功能。

## 技术栈

| 层级 | 技术 |
| --- | --- |
| 管理端 Web UI | Vue 3、TypeScript、Vite、Element Plus、Pinia、Vue Router、Vue I18n、ECharts |
| 后端服务 | Go 1.23、Gin、GORM、Viper、Logrus |
| 数据与缓存 | MySQL 8、可选 Redis |
| 接口与认证 | REST API、JWT、RSA、HMAC-SHA256 |
| 部署 | Docker、Docker Compose、Nginx |

| 目录 | 说明 |

| `frontend/src/views` | 管理端页面 |

## 核心模块

| 模块 | 当前职责 |
| --- | --- |
| 登录与公共框架 | 管理员登录、顶部导航、侧边导航、语言和页面容器；阶段一已统一 64px 顶栏、240/64px 侧栏及移动抽屉 |
| 仪表盘 | 有效授权、设备激活、剩余激活名额、到期提醒、授权码创建趋势、许可证激活趋势、最近授权与最近激活；保留社区版响应式视觉和雪松授权云推广区域 |
| 客户管理 | 客户查询、新增、编辑、详情、状态和关联授权入口 |
| 授权管理 | 客户选择、授权码列表、创建、详情、锁定、解锁、删除和许可证信息 |
| 发票管理 | 发票汇总、查询、详情、审核、开票和文件上传 |
| 套餐管理 | 套餐查询、新增、编辑、状态和删除 |
| 公共授权 API | 激活、心跳、许可证下载与校验相关能力 |
| 用户自助后端 | 注册、登录、订单、支付、设备、授权和发票接口；当前不属于本次管理端 Web UI 升级范围 |
