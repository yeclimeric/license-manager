## 2. 与任务清单的三处偏差

实施过程中发现原计划有两处判断不准确，已按实测调整。

### 2.1 S0-2 断点：原计划改 3 处，实际只需改 1 处

原计划把 `variables.scss:63` 的 `$breakpoint-tablet: 1024px` 改成 1023。**这个改法是错的**：

`mixins.scss` 用减一像素表达闭区间上限：

```scss
@mixin tablet {
  @media (min-width: #{$breakpoint-mobile}) and (max-width: #{$breakpoint-tablet - 1px}) {
```

若把变量改成 `1023`，平板区间会变成 **768–1022**，与项目中大量手写的 `768px~1023px` 媒体查询**直接矛盾**。

进一步核查发现，CSS 层其实早已统一在 1023：

| 位置 | 断点写法 | 与企业版 |
| --- | --- | --- |
| 企业版实测 | `(min-width:768px) and (max-width:1023px)` | 基准 |
| 社区版 CSS（多处方） | `(min-width:768px) and (max-width:1023px)` | ✅ 已一致 |
| `AuthorizationInfo.vue:361` | `max-width: 1024px` | ❌ 唯一 outlier |
| `variables.scss` 变量 | `1024px`（经 `-1px` 运算） | ✅ 实际等价 1023 |

**实际改动**：

- `AuthorizationInfo.vue:361`：`max-width: 1024px` → `1023px`（唯一真实不一致）
- `variables.scss`：加注释说明为何**不能**改 1023，防止后续误改
- `useDevice.ts`：加注释说明 JS 断点与 SCSS 的一致性依据

### 2.2 S0-3 圆角：38 处硬编码，但产出后仍有 15 处 `border-radius:0`

38 处全部改为 `$border-radius-base` 引用。构建后复查产物 CSS，仍有 15 处 `border-radius:0` —— 核查确认**来自 Element Plus 组件库自身**，非项目代码：

| 选择器 | 用途 | 企业版对照 |
| --- | --- | --- |
| `.el-button-group>.el-button:not(:first-child):not(:last-child)` | 按钮组中间段 | 同为 0 |
| `.el-checkbox-button__inner` | Checkbox 组各项 | 同为 0 |
| `.el-input-number__increase` / `__decrease` | 数字输入框增减按钮 | 同为 0 |
| `.el-dialog.is-fullscreen` | 全屏对话框 | 全屏语义 |

这些是**相邻元素拼接处的防双圆角设计**，属正常语义，不应修改。

**验证**：构建产物中 `--el-border-radius-base: 4px` 已生效，`border-radius:4px` 出现 31 处。

### 2.3 S0-4 枚举冲突：结论反转，改文档而非代码

原判断是「代码默认值 `basic` 与文档枚举冲突」。核查后发现**代码是自洽的，文档是过时的**：

| 载体 | 内容 | 判定 |
| --- | --- | --- |
| 三语语言包 | `basic`/`active`/`vip`/`strategic`/`other` → `1`~`5` | ✅ 一致 |
| 模型默认值 | `default:'basic'` | ✅ 与语言包一致 |
| Swagger 注释 | `Enums(basic, active, vip, strategic, other)` | ✅ 一致 |
| `customer.md` | `normal`/`vip`/`enterprise`/`strategic`，默认 `normal` | ❌ 过时 |
| `admin_database_tables.md` | 枚举正确，但缺星级说明 | ⚠️ 不完整 |

进一步查到 commit `058a521`（2026-09-01）**刻意**做了这次改造 —— 提交信息写明「update customer levels to numeric values」，且同步改了三语语言包、Swagger、前端三个组件。**显示值为数字是星级评分的设计，不是 bug。**

**实际改动**：只修两份文档，补齐星级语义与历史变更记录，**未动任何代码**。
