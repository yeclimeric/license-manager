## 2. 六处偏差（已全部修复）

### 2.1 登录页控件圆角 4px → 企业版 8px ⚠️ 观感明显

| 元素 | 企业版 | 本地 |
| --- | --- | --- |
| 登录按钮 | `8px` | `4px` |
| 输入框 | `8px` | `4px` |

**根因**：企业版的 `--el-border-radius-base` 令牌是 4px，但登录页控件显式用了 8px。**令牌与实际渲染不一致** —— 只对齐令牌无法得到相同观感。

### 2.2 登录页控件字号 14px → 企业版 16px ⚠️ 观感明显

| 元素 | 企业版 | 本地 |
| --- | --- | --- |
| 登录按钮文字 | `16px` / `weight 500` | `14px` / `weight 600` |

字重方向相反：企业版更细更宽，本地更粗更窄。

### 2.3 登录页控件高度 48px → 本地 50/54px

| 元素 | 企业版 | 本地 |
| --- | --- | --- |
| 按钮 | `48px` | `50px` |
| 输入框 | `48px` | `54px` |

输入框高 6px，是三处里最容易被眼睛捕捉的。

### 2.4 表格表头背景 浅绿 → 企业版纯白 ⚠️ 观感明显

| | 企业版 | 本地 |
| --- | --- | --- |
| `th` 背景 | `rgb(255,255,255)` 纯白 | `rgb(226,240,234)` 浅绿 |
| `th` 字号 | `14px` | `13px` |
| `th` 高度 | `40px` | `46px` |
| `th` 字重 | `500` | 继承 |

企业版表头**无底色**，靠底部 1px 分隔线（`#EBEEF5`）区分行。本地浅绿底 + 更小字号 + 更高行高，密集表格里显得更重。

### 2.5 字体族不同（有意选择，非缺陷）

| | 企业版 | 本地 |
| --- | --- | --- |
| 字体 | `"Helvetica Neue", Helvetica, "PingFang SC", …` | `Noto Sans SC, -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", …` |

本地把 `Noto Sans SC` 放在首位。这**不是缺陷** —— 企业版在中文 Windows 上会退到微软雅黑，本地显式指定思源黑体，中文渲染更一致。

**建议保持现状**，但需确认这属于有意的字体决策，而非遗漏。

### 2.6 页面背景色 不同

| | 企业版 | 本地 |
| --- | --- | --- |
| `--app-bg-color` | `#F5F7FA` 冷灰 | `#EAF2EE` 淡绿 |

本地整体带淡绿调，企业版是中性冷灰。这是**风格取向**而非缺陷，但会影响整体观感一致性。

### 修复过程中发现的额外缺陷

**筛选栏横向溢出，按钮被截断**（1280px 视口下「查询/重置」不可见）。

实测：工具栏 `scrollWidth 1095 / clientWidth 990`，右侧被裁掉 105px。

**根因**：`minmax(280px,420px)` 有 280px 硬下限，加上 3×160px 固定列，宽度算不下。

**企业版的做法**：`minmax(0px, 1fr)` 可收缩轨道（实测其客户页 `scrollW = clientW = 992`，零溢出）。

已按此修正客户页与授权码列表页，复测两页均 `990 = 990` 无溢出。

## 4. 未修改项

**字体族保持现状** —— 企业版 `"Helvetica Neue", Helvetica, "PingFang SC", …`，本地 `Noto Sans SC, -apple-system, …`。

本地显式指定思源黑体，中文渲染比企业版在中文 Windows 上退到微软雅黑更一致。这是有意选择，非缺陷。

**许可证详情页的键值栅格未动** —— `grid-template-columns: 200px 140px 1fr` 位于详情面板内，空间充足且与工具栏无关。

| # | 偏差 | 性质 | 建议 |
| --- | --- | --- | --- |
| 1 | 登录页圆角/字号/高度（2.1–2.3） | **缺陷** | 建议对齐 —— 企业版是刻意的大控件登录页，本地偏紧凑 |
| 2 | 表头浅绿底（2.4） | **待确认** | 若追求「一致」则改为白底；若追求「本地品牌色」则保留 |
| 3 | 背景色绿 vs 灰（2.6） | **风格取向** | 需你判断整体基调 |
| 4 | 字体族（2.5） | 有意选择 | 建议保持 |

## 5. 核查方法说明（可复现）

```bash
# 企业版与本地分别测同一选择器
agent-browser eval '(() => {
  const el = document.querySelector(".el-input__wrapper");
  const s = getComputedStyle(el);
  return JSON.stringify({ radius: s.borderRadius, font: s.fontSize, h: s.height });
})()'

# 令牌对比
agent-browser eval '(() => {
  const cs = getComputedStyle(document.documentElement);
  const app = {};
  for (const n of cs) if (n.startsWith("--app-")) app[n] = cs.getPropertyValue(n).trim();
  return JSON.stringify(app, null, 1);
})()'
```

**注意**：两个站的 localStorage 相互独立，切换站点后需重新设置 `token`（key 为 `token`），否则会被重定向到登录页 —— 本次核查中遇到两次。
